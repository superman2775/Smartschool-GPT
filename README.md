# Bigger explanation

Add ai to smartschool, with support for 10+ providers, including free and paid options. The extension is designed to be user-friendly and accessible to everyone, regardless of their technical expertise. It allows users to easily integrate AI capabilities into their Smartschool experience, enhancing productivity and providing valuable insights.

The extension is built with a focus on privacy and security, ensuring that user data is protected at all times. API keys are stored locally in the user's browser, and cannot be accessed by other users or the owner of the Smartschool Assistant.

Have fun exploring the possibilities of AI in Smartschool, and don't hesitate to reach out for support if you need it!
